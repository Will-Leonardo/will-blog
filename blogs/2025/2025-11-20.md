### 题目 1：Vue 的 slot 插槽机制是如何实现的？作用域插槽的原理是什么？

::: details 参考答案

**什么是插槽？**

插槽就是组件设计时预留的“占位符”，在使用时父组件可以按照需要填充这些插槽。

**基本原理？**

Vue在编译模版时，会把插槽内容转成函数：

```js
// 父组件模板
<MyComponent>
  <p>这是插槽内容</p>
</MyComponent>

// 编译后（简化版）
h(MyComponent, {
  // 插槽内容被转换成函数
  default: () => [h('p', '这是插槽内容')]
})
```

子组件在渲染时，会调用这些插槽函数：

```js
// 子组件内部
render() {
  return h('div', [
    // 调用插槽函数，获取内容
    this.$slots.default?.()
  ])
}
```

插槽类型： 默认插槽(匿名插槽)、具名插槽、作用域插槽【重要】

1、作用域插槽会被编译成函数，接收子组件传递的数据：

```js
// 父组件模板
<List>
  <template #default="{ item }">
    <span>{{ item.name }}</span>
  </template>
</List>

// 编译后（简化版）
h(List, {
  // 作用域插槽是函数，接收子组件传递的数据
  default: (slotProps) => {
    return h('span', slotProps.item.name)
  }
})
```
2、子组件在渲染时，会调用插槽函数并传入数据：


```Vue
<!-- <MyComponent> 的模板 -->
<div>
  <slot :text="greetingMessage" :count="1"></slot>
</div>
```

```js
// 子组件内部（简化版）
render() {
  return h('ul', 
    this.items.map((item, index) => {
      return h('li', [
        // 调用插槽函数，传入数据
        this.$slots.default?.({
          item: item,
          index: index
        })
      ])
    })
  )
}
```

### 题目 2：请解释 React Hooks 的实现原理，为什么 Hooks 不能在条件语句中使用？

::: details 参考答案

`Hooks`的核心是依赖调用顺序来管理状态，React 内部用链表（或数组）存储每个 Hook 的状态，通过顺序匹配来定位对应的 Hook。

详细原理分析：

1、Hooks 的存储方式

```js
// React 内部（简化版）
const hooks = [];  // 存储所有 Hooks
let currentIndex = 0;

function useState(initialValue) {
  // 根据当前索引获取 Hook
  const hook = hooks[currentIndex] || { 
    state: initialValue,
    setState: null
  };
  
  // 保存 Hook
  hooks[currentIndex] = hook;
  currentIndex++;
  
  // 返回状态和更新函数
  return [hook.state, (newState) => {
    hook.state = newState;
    scheduleUpdate();
  }];
}
```

2、 为什么不能再条件语句中使用？

```js
function Component({ condition }) {
  // 第一次渲染：condition = true
  if (condition) {
    useState(1);  // Hook[0]
  }
  useState(2);    // Hook[1]
  
  // 第二次渲染：condition = false
  // if 语句不执行
  useState(2);    // Hook[0] ← 错位！原本应该是 Hook[1]
}
```

**为什么要这样子设计？**

- 简单高效：通过顺序匹配，不需要额外的标识符
- 性能优化：链表结构，查找和更新快
- 统一管理：所有 Hooks 统一存储和管理

**useEffect 的实现（简化版）**

```js
function useEffect(callback, deps) {
  const currentIndex = hookIndex;
  hookIndex++;
  
  const hook = hooks[currentIndex];
  
  // 检查依赖是否变化 (有变化需要更新)
  if (!hook || !areDepsEqual(hook.deps, deps)) {
    // 执行 effect
    if (hook?.cleanup) {
      hook.cleanup(); // 先清理上一次的 effect
    }
    
    const cleanup = callback();
    hooks[currentIndex] = {
      deps,
      cleanup
    };
  }
}
```

### 题目 3：什么是 RAF（RequestAnimationFrame）？它和 setTimeout 的区别是什么？

::: details 参考答案

**RAF 和 setTimeout 的区别**

1. 执行时机
RAF：
- 在浏览器下次重绘前执行
- 与屏幕刷新率同步（通常 60fps）
- 如果标签页不可见，会自动暂停

setTimeout：
- 在指定时间后执行
- 不关心浏览器刷新率
- 即使标签页不可见，也会继续执行

2. 性能差异
  
RAF：
```js
// 性能更好，因为和浏览器刷新同步
function animate() {
  update();
  requestAnimationFrame(animate);
}
```
setTimeout：
```js
// 可能造成不必要的重绘
function animate() {
  update();
  setTimeout(animate, 16); // 固定 16ms，但可能和刷新不同步
}
```

3. 精度差异

RAF：
- 自动适配屏幕刷新率
- 60Hz 屏幕：约 16.67ms
- 120Hz 屏幕：约 8.33ms
- 更精确，不会掉帧
  
setTimeout：
- 固定时间间隔
- 可能和屏幕刷新不同步
- 容易造成掉帧或重复渲染

### 题目 4：如何实现图片懒加载？有哪些优化策略？

::: details 参考答案

懒加载：图片进入可视区域时再加载，而不是一开始就全部加载。

实现方式

方法1： Intersection Observer API（推荐） 【交叉观察器】

现代浏览器推荐使用，性能更好：
```js
// HTML
<img data-src="image.jpg" alt="图片" class="lazy-image" />

// JavaScript
const images = document.querySelectorAll('.lazy-image');

const imageObserver = new IntersectionObserver((entries, observer) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      // 图片进入可视区域，加载图片
      img.src = img.dataset.src;
      img.classList.remove('lazy-image');
      // 加载后取消观察
      observer.unobserve(img);
    }
  });
});

// 观察所有图片
images.forEach(img => imageObserver.observe(img));
```

方法2： scroll事件 （传统方式）

兼容性更好，但性能较差：

```js
function lazyLoad() {
  const images = document.querySelectorAll('img[data-src]');
  
  images.forEach(img => {
    // 判断图片是否进入可视区域
    const rect = img.getBoundingClientRect();
    const isVisible = rect.top < window.innerHeight && rect.bottom > 0;
    
    if (isVisible) {
      img.src = img.dataset.src;
      img.removeAttribute('data-src');
    }
  });
}

// 监听滚动事件

// 初始加载时也检查一次

```

### 题目 5：什么是 Docker？如何在前端项目中使用 Docker？

::: details 参考答案

Docker 是一个容器化平台，用于打包应用及其依赖，实现“一次构建，到处运行”。 解决“在我的机器上能跑，在你的机器上泡不了”问题。

在项目中，我主要用 Docker 做这几件事：

- 统一开发环境，新同事拉取代码后直接运行容器
- CI/CD 自动化部署，构建镜像后推送到服务器
- 多环境部署，用同一个镜像部署到测试和生产环境
  
Docker 让部署更简单，环境更一致，是现代化前端项目的好工具。

### 题目 6：如何实现大文件的分片上传？

::: details 参考答案

**什么是分片上传？为什么要分片上传策略？**

将大文件分为多个小片段，逐个上传，最后再服务器合并。大文件直接上传容易失败，切成小块，及时某块失败，只需重传该块，不用重传整个文件。

**实现原理：**

核心思路：
- 前端：将文件切分成多个 chunk
- 上传：逐个上传每个 chunk
- 服务器：接收所有 chunk 后合并
- 断点续传：记录已上传的 chunk，失败时只重传失败的

**具体实现：**

1、文件分片

```js
// 将文件切分成多个 chunk
function createChunks(file, chunkSize = 2 * 1024 * 1024) { // 默认 2MB
  const chunks = [];
  let start = 0;
  
  while (start < file.size) {
    const end = Math.min(start + chunkSize, file.size);
    const chunk = file.slice(start, end);
    chunks.push({
      chunk,
      index: chunks.length,
      start,
      end,
      size: chunk.size
    });
    start = end;
  }
  
  return chunks;
}
```

2、上传单个chunk

```js
// 上传单个分片
async function uploadChunk(chunk, fileHash, index, total) {
  const formData = new FormData();
  formData.append('chunk', chunk.chunk);
  formData.append('hash', fileHash);
  formData.append('index', index);
  formData.append('total', total);
  formData.append('filename', chunk.filename);
  
  try {
    const response = await fetch('/api/upload/chunk', {
      method: 'POST',
      body: formData
    });
    
    if (!response.ok) {
      throw new Error('上传失败');
    }
    
    return await response.json();
  } catch (error) {
    console.error(`分片 ${index} 上传失败:`, error);
    throw error;
  }
}
```

3、并发上传（控制并发数）

```js
// 并发上传，控制并发数
async function uploadChunks(chunks, fileHash, concurrency = 3) {
  const results = [];
  const uploading = [];
  
  for (let i = 0; i < chunks.length; i++) {
    const chunk = chunks[i];
    
    // 创建上传 Promise
    const uploadPromise = uploadChunk(chunk, fileHash, i, chunks.length)
      .then(result => {
        results[i] = result;
        // 从上传队列中移除
        const index = uploading.indexOf(uploadPromise);
        if (index > -1) {
          uploading.splice(index, 1);
        }
      })
      .catch(error => {
        // 上传失败，记录错误
        results[i] = { error, index: i };
        const index = uploading.indexOf(uploadPromise);
        if (index > -1) {
          uploading.splice(index, 1);
        }
      });
    
    uploading.push(uploadPromise);
    
    // 控制并发数
    if (uploading.length >= concurrency) {
      await Promise.race(uploading);
    }
  }
  
  // 等待所有上传完成
  await Promise.all(uploading);
  
  return results;
}
```


完整代码实现：

```js
class ChunkUploader {
  constructor(options = {}) {
    this.chunkSize = options.chunkSize || 2 * 1024 * 1024; // 2MB
    this.concurrency = options.concurrency || 3; // 并发数
    this.onProgress = options.onProgress || (() => {});
  }
  
  // 计算文件 hash（用于断点续传）
  async calculateHash(file) {
    return new Promise((resolve) => {
      // 创建FileReader对象，用于读取文件内容
      const reader = new FileReader();

      // 设置文件读取完成时的回调函数
      reader.onload = async (e) => {
        // e.target.result 是文件的ArrayBuffer数据 （二进制数据）
        const buffer = e.target.result;

        // 使用Web Crypto API计算SHA-256哈希
        const hashBuffer = await crypto.subtle.digest('SHA-256', buffer);

        // 将哈希结果从ArrayBuffer转换为普通数组
        const hashArray = Array.from(new Uint8Array(hashBuffer));

        // 将每个字节转换为16进制字符串，并确保是2位长度
        const hashHex = hashArray.map(b => b.toString(16).padStart(2,   '0')).join('');

        // 返回最终的哈希字符串
        resolve(hashHex);
      };

      // 开始读取文件为ArrayBuffer格式 （将文件读取为二进制数据）
      reader.readAsArrayBuffer(file);
    });
  }
  
  // 检查已上传的分片
  async checkUploadedChunks(fileHash, total) {
    try {
      const response = await fetch(`/api/upload/check?hash=${fileHash}&total=${total}`);
      const data = await response.json();
      return data.uploadedChunks || [];
    } catch (error) {
      return [];
    }
  }
  
  // 上传文件
  async upload(file) {
    // 1. 计算文件 hash
    const fileHash = await this.calculateHash(file);
    
    // 2. 创建分片
    const chunks = this.createChunks(file);
    
    // 3. 检查已上传的分片（断点续传）
    const uploadedChunks = await this.checkUploadedChunks(fileHash, chunks.length);
    const uploadedIndexes = new Set(uploadedChunks); // 去重
    
    // 4. 过滤出需要上传的分片
    const chunksToUpload = chunks.filter((_, index) => !uploadedIndexes.has(index));
    
    // 5. 上传分片
    let uploadedCount = uploadedChunks.length;
    const total = chunks.length;
    
    const uploadPromises = chunksToUpload.map((chunk, index) => {
      return this.uploadChunk(chunk, fileHash, chunk.index, total)
        .then(() => {
          uploadedCount++;
          this.onProgress({
            uploaded: uploadedCount,
            total: total,
            percentage: Math.round((uploadedCount / total) * 100)
          });
        });
    });
    
    // 控制并发
    await this.uploadWithConcurrency(uploadPromises, this.concurrency);
    
    // 6. 通知服务器合并
    await this.mergeChunks(fileHash, file.name, total);
    
    return { fileHash, filename: file.name };
  }
  
  // 创建分片
  createChunks(file) {
    const chunks = [];
    let start = 0;
    
    while (start < file.size) {
      const end = Math.min(start + this.chunkSize, file.size);
      // File集成自Blob，Blob 对象有 slice() 方法用于截取数据片段，start，end表示其他事和结束位置（字节）
      const chunk = file.slice(start, end);
      chunks.push({
        chunk,
        index: chunks.length,
        start,
        end,
        size: chunk.size,
        filename: file.name
      });
      start = end;
    }
    
    return chunks;
  }
  
  // 上传单个分片
  async uploadChunk(chunk, fileHash, index, total) {
    const formData = new FormData();
    formData.append('chunk', chunk.chunk);
    formData.append('hash', fileHash);
    formData.append('index', index);
    formData.append('total', total);
    formData.append('filename', chunk.filename);
    
    const response = await fetch('/api/upload/chunk', {
      method: 'POST',
      body: formData
    });
    
    if (!response.ok) {
      throw new Error(`分片 ${index} 上传失败`);
    }
    
    return await response.json();
  }
  
  // 并发控制上传
  async uploadWithConcurrency(promises, concurrency) {
  // 存储当前正在执行的任务
    const executing = [];

    // 遍历所有任务
    for (const promise of promises) {
      // 为每个任务添加完成后的清理逻辑
      const p = promise.then(() => {
        // 任务完成后从执行队列中移除自己
        const index = executing.indexOf(p);
        if (index > -1) {
          executing.splice(index, 1);
        }
      });

      // 将任务加入执行队列
      executing.push(p);

      // 如果执行队列达到并发限制，等待任意一个任务完成
      if (executing.length >= concurrency) {
        await Promise.race(executing);
      }
    }

    // 等待所有剩余任务完成
    await Promise.all(executing);
  }
  
  // 合并分片
  async mergeChunks(fileHash, filename, total) {
    const response = await fetch('/api/upload/merge', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        hash: fileHash,
        filename,
        total
      })
    });
    
    if (!response.ok) {
      throw new Error('合并失败');
    }
    
    return await response.json();
  }
}

// 使用
const uploader = new ChunkUploader({
  chunkSize: 2 * 1024 * 1024, // 2MB
  concurrency: 3, // 并发 3 个
  onProgress: (progress) => {
    console.log(`上传进度: ${progress.percentage}%`);
  }
});

const file = document.querySelector('input[type="file"]').files[0];
await uploader.upload(file);
```

### 题目 7：请实现一个函数，实现数组的交集、并集、差集。

::: details 参考答案

**基础实现：**

1、交集

```js
// 方法1：使用 filter 和 includes
function intersection (arr1, arr2) {
 return arr1.filter(item => arr2.includes(item))
}
// 方法2：使用 Set（性能更好）
function intersection (arr1, arr2) {
  const set2 = new Set(arr2)
  return arr1.filter(item => set2.has(item))
}

// 方法2：去重版本
function intersection(arr1, arr2) {
  const set2 = new Set(arr2);
  const result = arr1.filter(item => set2.has(item));
  return [...new Set(result)]; // 去重
}

```

```js
function union (arr1, arr2) {
  return [...new Set([...arr1, ...arr2])]

//

  }, [])
```

```js
function difference(arr1, arr2) {
  const set2 = new Set(arr2);
  const result = arr1.filter(item => !set2.has(item));
  return [...new Set(result)]; // 去重
}

```

### 题目 8：请实现一个函数，实现数组的 rotate（旋转）。

::: details 参考答案

**什么是 数组旋转 ？**

将数组元素按指定的步数向左或向右移动。
```js
const arr = [1, 2, 3, 4, 5];
console.log(rotateLeft(arr, 2)); // [3, 4, 5, 1, 2]
```

实现方式：

1、基础向左旋转

```js
// 方法1：使用 slice 和 concat
function rotateLeft(arr, k) {
  if (arr.length === 0 || k === 0) return arr;
  
  // 处理 k 大于数组长度的情况
  k = k % arr.length;
  
  // 将前 k 个元素移到末尾
  return arr.slice(k).concat(arr.slice(0, k));
}
```

2、基础向右旋转

```js
// 方法1：使用 slice 和 concat
function rotateRight(arr, k) {
  if (arr.length === 0 || k === 0) return arr;
  
  k = k % arr.length;
  
  // 将后 k 个元素移到开头
  return arr.slice(-k).concat(arr.slice(0, -k));
}

```

3、进阶 旋转 （不创建新数组）

- 时间复杂度：O(n) - 每个元素被访问固定次数

- 空间复杂度：O(1) - 不需要额外数组

- 原地操作：不创建新数组，节省内存

```js
// 方法1：使用 reverse（三次反转）
function rotateLeftInPlace(arr, k) {
  if (arr.length === 0 || k === 0) return arr;
  
  k = k % arr.length;
  
  // 反转整个数组
  reverse(arr, 0, arr.length - 1);
  // 反转前 n-k 个元素
  reverse(arr, 0, arr.length - k - 1);
  // 反转后 k 个元素
  reverse(arr, arr.length - k, arr.length - 1);
  
  return arr;
}

function reverse(arr, start, end) {
  // 双指针从两端向中间移动
  // 每次交换指针所指的元素(直到相遇)
  while (start < end) {
    [arr[start], arr[end]] = [arr[end], arr[start]];
    start++;
    end--;
  }
}

// 测试
const arr = [1, 2, 3, 4, 5];
rotateLeftInPlace(arr, 2);
console.log(arr); // [3, 4, 5, 1, 2]
```

### 题目 10：Vue 的指令（directive）是如何实现的？如何自定义指令？

::: details 参考答案

**Vue的指令是什么？** 

指令是Vue提供的特殊属性，以 `v-` 开头，用于在DOM元素上应用响应式行为，例如`v-if`

基本原理：

```js
// 模板
<div v-if="show">内容</div>

// 编译后（简化版）
h('div', {
  directives: [{
    name: 'if',
    value: show,
    expression: 'show'
  }]
})
```

指令的生命周期

```js
// 指令的生命周期
{
  bind(el, binding, vnode) {
    // 指令第一次绑定到元素时调用
  },
  inserted(el, binding, vnode) {
    // 被绑定元素插入到父节点时调用
  },
  update(el, binding, vnode, oldVnode) {
    // 所在组件的 VNode 更新时调用
  },
  componentUpdated(el, binding, vnode, oldVnode) {
    // 所在组件的 VNode 及其子 VNode 全部更新后调用
  },
  unbind(el, binding, vnode) {
    // 指令与元素解绑时调用
  }
}
```


```js
// 权限指令
Vue.directive('permission', {
  inserted(el, binding) {
    const permission = binding.value;
    const userPermissions = getUserPermissions(); // 获取用户权限
    
    if (!userPermissions.includes(permission)) {
      el.style.display = 'none';
      // 或者直接移除元素
      // el.parentNode.removeChild(el);
    }
  },
  update(el, binding) {
    // 权限变化时更新
    const permission = binding.value;
    const userPermissions = getUserPermissions();
    
    if (userPermissions.includes(permission)) {
      el.style.display = '';
    } else {
      el.style.display = 'none';
    }
  }
});

// 使用
<button v-permission="'delete'">删除</button>

```

总结

- 指令的实现原理：编译时识别，运行时处理，有生命周期钩子
- 如何自定义：全局注册或局部注册，实现生命周期钩子
- 实际应用：自动聚焦、防抖、拖拽、权限控制、复制等

在项目中，我主要用自定义指令做这些事：

1. 封装常用的 DOM 操作（聚焦、拖拽等）
2. 实现权限控制（根据权限显示/隐藏元素）
3. 优化性能（懒加载、防抖等）

指令的本质是封装 DOM 操作，让模板更简洁，代码更易维护。理解指令的原理，能更好地使用和自定义指令。
