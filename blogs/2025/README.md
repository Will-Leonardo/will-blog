# 前端面试刷题记录

## 📚 使用说明

### 自动生成刷题记录

每天运行以下命令即可自动生成当天的10道面试题：

```bash
# 生成今天的刷题记录
npm run question

# 或者直接运行脚本（生成今天的）
node generate-question.js

# 生成指定日期的刷题记录
node generate-question.js 2025-11-06
```

### 添加新的面试题

当你从网上（掘金、牛客网、GitHub、面试经验分享等）找到真实的面试题时，可以使用以下命令添加到题目库：

```bash
# 交互式添加题目
npm run question:add

# 或者直接运行
node add-question.js
```

添加题目时，脚本会引导你：
1. 选择题目类别（框架、浏览器、工程化等）
2. 输入题目内容
3. 选择是否需要代码实现
4. 记录题目来源（方便追踪）

### 答题建议

1. **独立完成**：先不看答案，独立思考和回答
2. **记录答案**：在"我的答案"区域填写你的答案
3. **查阅资料**：完成后查阅相关资料，补充"参考答案"
4. **总结复盘**：每天完成后填写"今日总结"，记录掌握情况
5. **定期复习**：每周回顾一次，巩固知识点
